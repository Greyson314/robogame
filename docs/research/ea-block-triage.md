# EA block/mechanic triage — 2026-07-28

Mirror of the ideation triage posted on Wayfinder issue
[#15 "Audit the EA block roster"](https://github.com/Greyson314/robogame/issues/15).
~70 ideas pitched one-by-one and triaged by the user. Feedstock for the
roster audit's keep/cut/add pass — not a resolution of #15. The issue
comment is canonical; this file is the in-repo copy for planning work.

## EA roster (user-approved for day one)

- **Sticky wheels** — grip walls/ceilings by realigning "down" to the contact normal
- **Air brake / flaps** — drag on demand
- **Sail block** — wind force; wakes up under the wind modifier
- **Scattergun** — close-range spread burst (flagship for the spread concoction lever)
- **Flak cannon** — proximity-airburst anti-air
- **Jammer module** — disables enemy modules in a radius
- **Rally banner module** — team aura; *user wants multiple flavors designed* (repair tick / reload / speed etc.)
- **Bounty mechanic** — scrap-richest player marked + worth bonus scrap
- **Modifiers: gravity dial + wind storm** — must be toggleable via server/lobby match config, NOT client Tweakables (invariant #1)
